# Spec index

Read the document for the area you change. Do not load every file.

| Document          | Mode                 | Read when                                                              |
| ----------------- | -------------------- | ---------------------------------------------------------------------- |
| `architecture.md` | Explanation          | You need the module map, data flow, or ownership boundaries            |
| `data-model.md`   | Reference            | You change a table, status, time field, or index                       |
| `ingestion.md`    | Explanation          | You change message writes, jobs, retries, or chunking                  |
| `annotation.md`   | Explanation          | You change extraction, entity resolution, or state links               |
| `retrieval.md`    | Explanation          | You change a retrieval channel, fusion, expansion, or context assembly |
| `api.md`          | Reference            | You call or extend the public API                                      |
| `providers.md`    | Reference            | You add or configure a model provider                                  |
| `testing.md`      | How-to               | You add tests or run the suite                                         |
| `benchmark.md`    | How-to and reference | You run the benchmark or report a result                               |
| `roadmap.md`      | Reference            | You need the implemented scope or the deferred work                    |

`docs/decisions.md` records architecture decisions and the verification run behind the first release.
